# Diplom_2 — API-тесты для Stellar Burgers

Автотесты для проверки API космической бургерной Stellar Burgers.

## Реализованные сценарии

### Создание пользователя
- Создание уникального пользователя
- Создание дубликата пользователя
- Создание пользователя без обязательного поля

### Логин пользователя
- Вход под существующим пользователем
- Вход с неверным логином и паролем

### Создание заказа
- С авторизацией
- Без авторизации
- С ингредиентами
- Без ингредиентов
- С неверным хешем ингредиентов
